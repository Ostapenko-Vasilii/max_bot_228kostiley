# **Общажный бот**
## Перед запуском

Перед запуском желательно узнать свой id  в max, если вы уже запустили бота и не знатете свой id вы можете после регитсрации перейти в настройки, там будет ваш id.

## Локального запуска
Для локального запуска вам после разархинирования папки надо открыть терминал и перейти в папку проекта и написать 4 команды:

1. ```npm install sql.js```

2. ```npm install dotenv```

3. ```npm install @maxhub/max-bot-api```

4. ```npm start```
   
### Что делать при ошибке?
_С 1 ноября api для max ботов поменялся_, так что перейдите в библиотеку **dist/core/network/client.js**  и смените *base url* на https://
platform-api.max.ru
## Запуск через образ
Для запуска через образ вам после разархинирования папки надо открыть терминал и перейти в папку проекта и написать 2 команды:

1. ```docker load -i ./dormitory_bot.tar```
    + после установки он вам покажет
    > Loaded image ID: sha256: image_id
    - Скопируйте то, чо идёт после `sha256:` 
2. ```docker run -e BOT_TOKEN=ваш_токен -e PRORAB_ID=ваш_id id_image```
3. для получения роли прораба вам нужно
   - PRORAB_ID=ваш_id (id можно всзть в настройках после регестрации)
      вы можите запустить с рандомным id, потом пройти регестрацию посмотреть свой id,
     перезапустить со воим id 
     !!!!! Для получение роли (если вы правильный id после регестрации в приложении, нужно зайти в настройки (в меню бота)) !!!!!
     с помощью этой роли вы можете выдать себе все остальные роли (прораб панель -> назначить роли -> вводите свой id)

!!! сервера max плохо работают через vpn
